# Release Assets - Version 2.1.0

This directory contains all 28 Magisk module zip files for SMbootFX version 2.1.0.

## Contents

Each zip file includes:
- `module.prop` - Module properties with version 2.1.0 and versionCode 210
- `update.json` - Update configuration with correct 2.1.0 release URLs
- `CHANGELOG.md` - Changelog with 2.1.0 release notes
- Boot animation files and installation scripts

## Upload Instructions

These zip files should be uploaded to the GitHub release page for version 2.1.0:
https://github.com/John0n1/SMbootFX/releases/tag/2.1.0

**Important:** These files replace the existing zip files in the release, as they contain updated internal version information (update.json, CHANGELOG.md, and module.prop all reference version 2.1.0).
